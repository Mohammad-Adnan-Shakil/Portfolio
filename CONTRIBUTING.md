# Contributing

Thank you for considering contributing to the Portfolio project.

## Code of Conduct

By participating, you agree to maintain a respectful and inclusive environment.

## How to Contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b feat/your-feature-name`
3. Commit your changes with a descriptive message.
4. Push to your fork and open a pull request.

## Pull Request Guidelines

- Keep PRs focused on a single concern.
- Ensure the app builds successfully (`npm run build`).
- Run the dev server (`npm run dev`) and verify no console errors.
- Update relevant documentation if your change affects architecture or setup.

## Development Setup

```bash
npm install
npm run dev
```

## Reporting Issues

Open a GitHub issue with a clear title, description, and steps to reproduce.
